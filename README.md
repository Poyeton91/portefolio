# Portfolio

Portfolio statique en HTML, CSS et JavaScript, prévu pour GitHub Pages. Aucun outil de build ou serveur applicatif n'est nécessaire.

## Structure

- `index.html` : structure et contenu du site
- `css/styles.css` : styles
- `js/app.js` : interactions et fiches des projets
- `images/<projet>/` : couverture et photos de chaque projet

## Ajouter des photos

Ajoute le fichier dans le dossier du projet, puis ajoute son chemin à la liste `images` de ce projet dans `js/app.js`. La couverture est définie à part dans `cover`.

Publie ensuite le site sur GitHub Pages depuis la branche principale et le dossier racine.
